# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of Vortex Downloader and its users seriously. If you discover a security vulnerability or bug:

1. **Please do not report security vulnerabilities through public GitHub issues.**
2. Instead, please report them directly to our security and support desk:
   - **Email**: [support@vortexdownloader.org](mailto:support@vortexdownloader.org)
   - **Official Resolution Desk**: [https://vortexdownloader.org/report-a-bug/](https://vortexdownloader.org/report-a-bug/)

We will acknowledge receipt of your vulnerability report within 24 hours and provide a detailed timeline for patch release and mitigation.
